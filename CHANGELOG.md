# Changelog

## 2.0.0 (2026-11-01) - companion code for the restructured book

* One library (`pinnode/`) shared by every example: architectures (MLP, Chebyshev, Legendre,
  Fourier-feature, SIREN, hard-constraint wrappers), automatic-differentiation helpers,
  quadrature, two-stage Adam -> L-BFGS training with full histories, classical reference
  solvers, metrics and a single figure style.
* All examples ported to **PyTorch** (the TensorFlow scripts of chapters 3-4 were rewritten),
  run in **double precision** with **fixed seeds**, on CPU, in minutes instead of hours.
* Folder structure follows the book: `chapters/ch01_formulation/` ... `chapters/ch12_further_classes/`
  (replaces the duplicated `Chapter 2/IVP` and `Chapter2/IVP` folders and the misspelt
  `Chapter 5/Intergral Equ`).
* New examples for the new chapters: architectures and hard constraints, adjoint and
  forward-backward (LQR) problems, training failure modes and remedies, benchmarks against
  RK/BDF/collocation/shooting/Nystrom, inverse problems and uncertainty quantification,
  singular, delay, fractional, DAE, eigenvalue and time-scale problems.
* `--quick` smoke-test mode for every script, `pytest` suite and GitHub Actions workflow.
* Pinned environment (`requirements-lock.txt`), `CITATION.cff`, Zenodo metadata, MIT license.
* Assignment notebooks (`notebooks/`) for every chapter.
* Animated README artwork generated by `scripts/make_readme_assets.py` and
  `scripts/make_animations.py`.

## 1.0.0 (2025)

* Initial upload of the first-manuscript scripts (Colab-oriented, mixed TensorFlow/PyTorch).
